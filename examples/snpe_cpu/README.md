# SNPE CPU Runtime Sample

Demonstrates single-model inference using the Atlas SNPE backend with __CPU__ as the SNPE runtime.

## Platform Constraint

The SNPE backend is only functional on:
- **Linux aarch64**
- **Android arm64**

On other platforms (macOS, Linux x86_64) the SNPE stub returns `kBackendNotFound`. The example handles this gracefully.

## Prerequisites

- Bazel 6.5+
- SNPE SDK installed (set `SNPE_SDK_PATH` environment variable)
- Python 3 with `onnx` package (`pip install onnx`)
- Target: Linux aarch64 or Android arm64 device

## Quick Start

```bash
# 1. Generate the .dlc model (requires SNPE SDK)
python3 examples/snpe_cpu/gen_models.py /tmp/snpe_sample_models

# 2. Export the model directory
export SAMPLE_MODEL_DIR=/tmp/snpe_sample_models

# 3. Build
bazel build //examples/snpe_cpu:snpe_cpu

# 4. Run
./bazel-bin/examples/snpe_cpu/snpe_cpu \
    examples/snpe_cpu/manifest.json
```

## What This Sample Covers

| Atlas Module | Usage in Sample |
|---|---|
| `AtlasRuntime::Init()` | Parses manifest, creates shared `SnpeBackendContext` |
| `AtlasRuntime::GetModel()` | Obtains `ModelHandle` for SNPE model |
| `Pipeline::BuildInputPipeline()` | Auto-built from SNPE runtime tensor info: DtypeConvert -> Resize -> BGRToRGB |
| `SnpeBackend::Load()` | Loads `.dlc` container, builds SNPE network with CPU runtime |
| `SnpeBackend::Infer()` | Executes inference via SNPE CPU_FLOAT32 |
| `ModelHandle::Run()` | One-call preprocessing + inference |
| `ErrorCode::kBackendNotFound` | Graceful handling of unsupported platforms |

## SNPE Config Fields

The `config` block in `manifest.json` supports these SNPE-specific fields:

| Key | Values | Default | Description |
|-----|--------|---------|-------------|
| `runtime` | `cpu`, `gpu`, `dsp`, `aip` | `gpu` | SNPE runtime target |
| `performance_profile` | `default` / `balanced`, `high_performance`, `power_saver`, `system_settings`, `sustained_high_performance`, `burst`, `low_power_saver`, `high_power_saver`, `low_balanced`, `extreme_power_saver` | `balanced` | Performance mode |
| `use_buffer` | `"true"`, `"false"` | `false` | Use user-supplied buffers |

This example uses `"runtime": "cpu"` to run inference on the SNPE CPU backend.

## Model Used

- **File**: `identity_snpe.dlc` (generated by `gen_models.py`)
- **Type**: Identity operator (output = input)
- **Source ONNX Shape**: `[1, 3, 4, 4]` (NCHW)
- **Runtime SNPE Shape**: `[1, 4, 4, 3]` (NHWC)
- **Data Type**: Float32
- **Purpose**: Simplest possible model to verify end-to-end SNPE pipeline

## Troubleshooting

### `SNPE_SDK_PATH` is not set

```bash
export SNPE_SDK_PATH=/path/to/snpe-sdk
```

### `snpe-onnx-to-dlc` not found

Ensure SNPE SDK host tools (Linux x86_64) are installed. The converter lives at:

```
$SNPE_SDK_PATH/bin/x86_64-linux-clang/snpe-onnx-to-dlc
```

### `kFileNotFound` on Init

Ensure `SAMPLE_MODEL_DIR` is set and the `.dlc` file was generated:

```bash
ls $SAMPLE_MODEL_DIR/identity_snpe.dlc
```
